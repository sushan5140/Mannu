# Mannu — Proof of Mannu

A playful identity-verification mini-game disguised as a gift unlock.

## What it does
- One-question-at-a-time game flow
- 20 prompts across favorites, comfort things, gift preferences and personal lore
- Autosaves progress locally in the browser
- Skip/back/edit support
- Generates a final **Mannu Passport**
- Share, copy or download the full verification receipt
- No backend and no automatic uploads

## Run
Open `index.html` directly, or serve the folder with any static server.

## Deploy
The project is static and works on Vercel, Netlify, GitHub Pages, Cloudflare Pages, etc.

## Privacy
Answers are stored only in browser `localStorage` until the player explicitly uses Share, Copy or Download.
